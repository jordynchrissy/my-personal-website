This project is a personal website designed to introduce me and present information about my interests, activities, and personal preferences. It provides visitors with a simple and organised way to explore the content of the website.

# Redesign Summary!

The redesign focuses on improving the website's overall appearance, layout, navigation, and user experience. Improvements include organising the content more clearly, refining the styling, and making the website easier to navigate across different screen sizes.

## Reflection ♡

Redesigning my personal website was definitely a learning experience, with a few struggles along the way. My main goal was to improve the website's overall appearance by making the layout more organised, improving the colours, and using visual elements to make it more appealing. I also worked on making the website responsive so that it could be viewed on mobile phones, tablets, and desktop computers. Additionally, I organised my HTML and CSS code and added comments to make everything easier to understand and maintain.

One of my biggest challenges was dealing with my CSS. At one point, it felt like there were unnecessary lines everywhere, and trying to clean everything up without accidentally removing important styling was a task of its own. It taught me that writing code is not just about getting the website to look good; it is also about keeping everything organised and making sure that changes do not cause new problems. Needless to say, patience was important!

I also learned more about GitHub and how branches and Pull Requests work. Creating a separate branch allowed me to work on my redesign without making changes directly to the main branch. I also learned how Pull Requests help organise and review changes before they are merged. Overall, this project improved my web design skills and taught me the importance of organisation, patience, and proper version control. It was a challenge, but seeing the improvements made the effort worthwhile. :)
