# About my Website!

This project is a personal website designed to introduce me and present information about my interests, activities, and personal preferences. It provides visitors with a simple and organised way to explore the content of the website.

# Redesign Summary!

The redesign focuses on improving the website's overall appearance, layout, navigation, and user experience. Improvements include organising the content more clearly, refining the styling, and making the website easier to navigate across different screen sizes.

# JavaScript Enhancements!

JavaScript was incorporated to make the website more interactive, dynamic, and engaging. Five main features were implemented using DOM manipulation, event handling, and text processing.

# Five JavaScript Features

1. *Dark and Light Mode Toggle*

- Allows visitors to switch between light and dark themes.
- Uses JavaScript to toggle a CSS class on the document body.
- Updates the button text depending on the selected theme.

2. *Automatic Image Slideshow*

- Displays multiple graphic design projects within the portfolio.
- Visitors can manually navigate between images using previous and next buttons.
- Automatically changes images every four seconds.
- Includes a sliding transition animation.

3. *Digital Clock*

- Displays the current date and time on the website.
- Uses JavaScript's Date object to retrieve and format the current date and time.
- Automatically updates every second.

4. *Random Welcome Greeting*

- Displays a welcome popup when visitors open the website.
- Generates a random inspirational quote from a predefined collection.
- Allows visitors to generate another quote or close the popup.

5. *Website-Wide Search and Text Counter*

- Allows visitors to search for text throughout the website.
- Highlights matching text within the website's content.
- Displays a live word count and character count as visitors type.
- Updates the results dynamically using DOM manipulation.

*Additional visual enhancements include page-load animations and scroll-reveal animations to make the website more engaging.*

## Reflection ♡

Redesigning my personal website was definitely a learning experience, with a few struggles along the way. My main goal was to improve the website's overall appearance by making the layout more organised, improving the colours, and using visual elements to make it more appealing. I also worked on making the website responsive so that it could be viewed on mobile phones, tablets, and desktop computers. Additionally, I organised my HTML and CSS code and added comments to make everything easier to understand and maintain.

One of my biggest challenges was dealing with my CSS. At one point, it felt like there were unnecessary lines everywhere, and trying to clean everything up without accidentally removing important styling was a task of its own. It taught me that writing code is not just about getting the website to look good; it is also about keeping everything organised and making sure that changes do not cause new problems. Needless to say, patience was important!

Developing my personal website with JavaScript allowed me to make it more interactive and functional. I implemented five main features: a dark and light mode toggle, an automatic image slideshow, a digital clock, a random welcome greeting, and a website-wide search feature with live word and character counters. I also added animations to improve the overall user experience.

One of the challenges I encountered was ensuring that the JavaScript features worked correctly with my existing HTML and CSS without affecting the website's original design. I also had to work through issues involving DOM selection, event listeners, and updating content dynamically. These experiences helped me better understand how JavaScript interacts with HTML elements and how DOM manipulation can be used to change a webpage in response to user actions.

I learned more about GitHub and how branches and Pull Requests work. Creating a separate branch allowed me to work on my redesign without making changes directly to the main branch. I also learned how Pull Requests help organise and review changes before they are merged. Overall, this project improved my web design skills, understanding of JavaScript, and taught me the importance of organisation, patience, and proper version control. It was a challenge, but seeing the improvements made the effort worthwhile. :)
